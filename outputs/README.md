# Outputs

This folder contains the exported outputs of the CloudFormation stacks used in the project.

- `01_AWS_Network_Outputs.txt` — VPC, subnet, route table and security group identifiers

The full set of stack outputs (storage, identity), the KMS key policy and the additional IAM role policies are retained privately by the author and can be supplied on request. They are intentionally not committed to the public repository because they contain infrastructure identifiers that are not required to reproduce the design from the templates in `infra/`.
